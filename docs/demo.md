# Reproducible judging demonstration

Start with `npm start` (or `start.ps1` for local credential configuration). Explain that MORS studies microgravity combustion using a five-record NASA PSI-69 table extract. The full archive and calibrated imagery are not bundled.

1. Open Dataset Explorer: show the records, source DOI and the missing extinction diameter. State that source attribution is not an independent remeasurement.
2. Open the interactive research workspace: choose a variable, select a point, inspect its units and experiment ID, and verify against the bundled source record.
3. Filter experiments and inspect linked statistics. Explain that filtering changes the sample and that five selected tests cannot establish population or causal conclusions.
4. Compare measurements, inspect quality notes, and save a research annotation and reproducible configuration.
5. Run Agent Operations. Show the validation/review gates, rejected-input behavior, permissions and execution mode. Deterministic stages are explicitly identified.
6. Ask Copilot about limitations. Inspect the provider label: an unavailable external model uses a clearly labeled local summary. Never present the fallback as a live model answer.
7. Export the configuration, underlying data and report. Explain how another researcher can reproduce the arithmetic mean (0.556 mm/s for the bundled rows, using their reported units).

Offline resilience: bundled analysis and provenance inspection do not depend on satellite APIs or Gemini. FIRMS is optional context, and hotspots are satellite observations, not confirmed fire perimeters. Habitat telemetry, calibrated video playback and quantum advantage claims are outside demonstrated capabilities.

Judging criteria: no specific competition edition or published rubric was supplied. Map the demonstration provisionally to scientific credibility, usable interaction, reproducibility and reliability. Do not describe these as official judging weights.
